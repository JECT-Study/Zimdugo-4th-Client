# 보관함 정확성 투표 레거시

보관함 상세 개편에서 정확성 투표 UI와 런타임 연결을 중단했다.
기존 동작을 롤백할 수 있도록 API, 세션 모델, 훅, 오버레이와 테스트를 이 디렉터리에 보존한다.

## 복원 순서

1. 홈 라우트에서 `useVoteLockerSession`을 생성한다.
2. 상세 데이터에 `applyVoteOverlayToLockerDetail`을 적용한다.
3. 상세 바텀시트에 vote 변경 콜백과 정확성 투표 액션을 복원한다.
4. 시트 이탈 시 favorite와 함께 vote 세션의 `flush`를 호출한다.

새 기능은 이 디렉터리에 추가하지 않는다.
